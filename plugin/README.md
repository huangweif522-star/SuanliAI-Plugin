# 算力AI视频 v1.1.4

插件版本：1.1.4。安装文件夹：`Suanli_Ai_v1.1.4`。

## 本版调整

- 底部新增“检查更新”和“下载新版”，使用独立 GitHub 仓库 [SuanliAI-Plugin](https://github.com/huangweif522-star/SuanliAI-Plugin)。
- 当前已选模型卡片与列表选中项同步高亮，并显示已选标记。

- 时长只保留 **15 秒、30 秒**，默认 **30 秒**，保存和实际提交均使用整数。
- 移除“使用分镜时长”。旧配置中即使启用了该选项，也不会覆盖当前选择的时长。
- 旧配置的 5 秒、10 秒、小数和其他非 15/30 秒值统一重置为 **30 秒**；明确保存的 15 秒或 30 秒保留，不追加其他时长选项。
- 默认生成模式为 **多参考图生成视频**。已有明确保存的生成模式仍会保留。
- 压缩包和内部文件夹统一按版本号命名为 **Suanli_Ai_v1.1.4**。
- 对照 [算力 AI 接口文档](https://suanliai.top/docs) 核对请求字段，并兼容提交响应中的 `id` 和 `task_id` 两种任务号字段。

- 固定黑灰配色，与原插件风格一致，不再跟随系统浅色设置变白。
- 接口设置、模型检索、生成设置、参考素材和等待设置分区展示，用不同深浅和细色标区分。
- 默认时长 **30 秒**，默认画幅比例 **9:16**，默认最长等待 **3600 秒**。
- 分类、关键词搜索、在线更新和失败保留模型列表的行为继续保留。

从 1.1.0 升级时，未更改过的完整旧默认组合（10 秒、16:9、900 秒）会自动更新为本版默认值，并保存一次升级标记。其他自定义比例、等待时间和生成模式会保留；所有来源的时长都按本版 15/30 秒规则处理。

## 安装

1. 解压安装包，得到 `Suanli_Ai_v1.1.4` 文件夹。
2. 推荐将整个文件夹放入字字动画安装目录中的 `user_resources/plugins/video_plugins/`（没有目录时可创建）。原来的 `_internal/plugins/video_plugins/` 安装位置也可继续使用。
3. 确认目录为 `video_plugins/Suanli_Ai_v1.1.4/main.py`，不要多套一层同名目录。
4. 重启字字动画，在视频插件列表选择“算力AI视频 v1.1.4”。
5. 填写自己的 API 令牌；接口地址默认 `https://suanliai.top/v1`。

新版使用独立文件夹，可与原插件并存。宿主通常按插件文件夹保存配置，改名后首次使用可能需要重新填写令牌和参数。新版保留原参数名称，支持宿主传入的原模型名称；不读取其他插件的令牌。

## 插件版本更新

在底部版本区点击“检查更新”。只在主动点击时访问本仓库的公开 GitHub Releases，显示最新版本及更新说明；检查版本不需要算力 AI 令牌。

有新版时点击“下载新版”。安装包会保存至本机下载目录，界面显示完整路径。下载过程校验 SHA-256、ZIP 完整性、版本号和包内目录；不使用算力 AI 令牌，不会将账号设置发送到 GitHub。

下载完成后解压，将新版本文件夹放入视频插件目录并重启字字动画，在插件列表选择新版本。每个版本使用独立文件夹和宿主配置，首次使用新版本需填写该版本的令牌。

GitHub 暂时不可用时，可稍后重试，或从 [Releases](https://github.com/huangweif522-star/SuanliAI-Plugin/releases/latest) 手动下载。

## 找模型

- 内置原插件去重后的 111 个模型。
- 按模型家族筛选：SD2.0、SD2.5、SD2.5 Pro、MiniMax、Wan3、Grok、视频编辑及其他。
- 按来源系列筛选：002、003、004、006、007、专享；在线更新出现的新系列会加入筛选。
- 粘贴完整模型名称可直接定位；多个关键词用空格、逗号或换行分开，结果需同时满足各关键词。
- 例如 `minimax 2k`、`sd2.5 720p 30图`。检索忽略英文大小写，并兼容常见空格、全半角和 MiniMax H3 名称分隔写法。
- 搜索“卡脸”不会把“不卡脸”当作命中；“过人脸”和“过真人”可互相检索，“不卡脸”保持独立。
- 分类和检索只改变显示结果，点击结果才切换模型。当前配置的模型不在目录时仍保留，并显示提示。

模型名称中的时长、清晰度、过脸和参考数量仅用于检索，不构成能力验证。插件提交时使用完整原始模型 ID，不改写中文、大小写、斜杠、括号和空格。

接口文档说明，平台可能把不受支持的秒数调整到模型允许的档位。因此，生成 30 秒视频需要选择支持 30 秒的模型；插件不会为了适配模型自行把提交值改成 5 秒或 10 秒。

## 在线更新模型

填写接口地址和令牌后，点击“更新模型”。插件后端向当前地址的 `/models` 读取目录（默认完整地址为 `https://suanliai.top/v1/models`），不提交视频生成任务。打开面板读取本地目录，不自动联网更新。

成功后显示目录来源、数量、更新时间和本次增减，并保存到本机用户目录。缓存按接口地址及令牌摘要区分，不保存令牌明文。更换地址或令牌后不沿用上个账号的在线目录。

网络超时、鉴权失败、返回为空或格式不受支持时不会覆盖上次有效缓存。无有效缓存时使用内置目录。更新后不自动更换当前已选模型；不认识的新模型放入“其他／待识别”，明确属于文字、图片或音频的条目会排除。

已核对当前电脑中字字动画的插件指南和 SDK，支持在线更新所用的插件动作回调。若提示宿主未连接或超时，请在字字动画中重新打开插件；内置模型的分类和搜索仍可使用。

## 生成参数与素材

保留原插件的 API 令牌、接口地址、模型、生成模式、比例、分辨率、声音、过脸、参考视频与音频、查询间隔和最长等待等参数。生成时长仅使用插件内所选的 15 秒或 30 秒。

- 文生视频不发送宿主参考图片。
- 首帧生成优先使用宿主首帧，否则使用第一张参考图片。
- 首尾帧依次发送宿主首帧和尾帧，具体支持情况以模型为准。
- 多参考图生成会合并参考图片及首尾帧，按原逻辑去除相同路径。
- 视频和音频参考每行填写一个 URL 或本地路径；本地素材转换为 Base64，单个素材上限 50 MB。
- 实际请求通过 `seconds` 字段提交所选时长，分镜时长不参与覆盖。

原生成流程继续只提交一次任务，不自动重试提交。连接中断或超时后，先在平台控制台核查原任务，避免重复提交。模型在目录中不等于当前渠道可用，最终以平台响应为准。

## 验证范围

已用离线模拟响应检查模型读取、更新、缓存、搜索与原生成流程，不包含真实令牌，不会附带用户缓存或测试状态。平台的模型列表入口在匿名访问时要求鉴权；带令牌的实际模型目录与字字动画内的完整运行效果，需安装后使用自己的账号验证。
